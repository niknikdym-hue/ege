# Eksamio — ЕГЭ физика 2026: verification gate

Статус: `SOURCE_PRELOCK_OPEN / DEMO_NOT_FROZEN`.

## Назначение

Этот gate переносит на физику уже принятый в репозитории процесс создания и проверки демоверсий базовой и профильной математики. Новый параллельный процесс не создаётся.

Physics 2026 уже существует как продукт `ege-fizika-demoversiya-v3.zip`. Он проверяется и при необходимости исправляется; не пересобирается без подтверждённой причины.

## Authority

Единственный content authority для 2026:

- FIPI page: `https://fipi.ru/ege/demoversii-specifikacii-kodifikatory`
- approved Physics package: `https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2026/fi_11_2026.zip`
- required official set: demo + codifier + specification.

`ege-fizika-demoversiya-v3.zip` — объект проверки, не source authority.

## Gate 0 — exact-year source lock

PASS только если:

- официальный ZIP сохранён без изменений;
- исходные PDF сохранены в `original/` без редактирования;
- зафиксированы имена, размеры и SHA256 ZIP + каждого PDF;
- подтверждено, что это утверждённый комплект 2026, а не проект;
- все дальнейшие content assertions трассируются к точной странице/фрагменту официального source.

До этого gate итоговый статус физики 2026 не может быть `PASS` или `FROZEN`.

## Gate 1 — exam structure

Проверить против официальной спецификации:

- 26 заданий;
- часть 1: 20 заданий с кратким ответом;
- часть 2: 6 заданий с развёрнутым ответом;
- 235 минут;
- максимальный первичный балл: 45;
- тип и максимальный балл каждой позиции 1–26;
- разрешённые справочные данные и инструкции;
- точный year-specific input contract для каждой позиции.

## Gate 2 — item-by-item fidelity matrix

Одна строка audit matrix на каждый официальный пример/ветку `ИЛИ`, а не одна строка на номер позиции.

Минимальные поля:

`exam_no, official_example_id, source_pages, task_text, numeric_data, units, formulae, visual, answer_or_solution, criteria, max_score, input_contract, demo_mapping, status, defect, evidence`.

Для каждого примера отдельно проверяются:

1. текст условия без смысловых подмен;
2. числа, знаки, степени, индексы и единицы;
3. формулы и обозначения;
4. графики, схемы, приборы, таблицы и рисунки;
5. все варианты `ИЛИ`;
6. официальный ответ для краткой части;
7. полное решение, критерии и максимальный балл для развёрнутой части;
8. соответствие элемента интерфейса именно этому примеру.

Наличие темы, формулы или похожей картинки не считается fidelity.

## Gate 3 — independent subject check

Независимо от данных, уже зашитых в демо:

- задания 1–20 решаются/проверяются заново;
- ответы сравниваются с официальной таблицей ответов;
- задания 21–26 сверяются по полным официальным решениям и критериям;
- все физические модели, знаки, направления сил/полей, графики, схемы и вычисления проверяются отдельно;
- найденные расхождения фиксируются как defects до исправления, а не объясняются постфактум.

Если правильный ответ можно получить при разных ошибочных рассуждениях, это не используется как основание для skill inference; это будет предметом более позднего identity/evidence audit.

## Gate 4 — interaction / scorer / state

Без изменения существующего scoring-контракта проверить фактическое поведение:

- ввод каждого допустимого типа ответа;
- неверный/верный/пустой ответ;
- переходы между заданиями;
- завершение попытки;
- правильность автоматического результата части 1;
- отсутствие автоматической подмены экспертной оценки заданий 21–26;
- timer/state/results behavior;
- restore после reload;
- отсутствие потери уже введённых ответов.

Найденный дефект можно исправлять в предметной ветке только если это не требует самовольного изменения production/localStorage/scoring architecture.

## Gate 5 — visual / responsive

Обязательные ширины по принятому math reference: `1280 / 768 / 390 / 360 / 320`.

Проверить:

- читаемость формул, таблиц, графиков и схем;
- отсутствие обрезания критериев и решений;
- отсутствие перепутанных границ соседних `ИЛИ`;
- отсутствие горизонтальных поломок интерфейса;
- отсутствие severe JavaScript errors.

## Gate 6 — clean ZIP regression

Финальный ZIP распаковывается в чистое окружение, после чего повторяется полный gate:

- source/content mapping;
- все официальные примеры;
- scorer;
- state/restore;
- responsive widths;
- critical JS errors.

PASS относится к финальному ZIP, а не к рабочей папке до упаковки.

## Freeze rule

`ACCEPTED-TECHNICAL-REFERENCE` для Physics 2026 создаётся только после:

1. закрытого source gate;
2. item-by-item audit PASS;
3. independent subject audit PASS;
4. browser/scorer/state/width/clean-ZIP PASS;
5. ручной пользовательской приёмки, если она требуется для статуса, аналогичного принятой профильной математике.

После freeze Physics 2026 может быть техническим reference для 2025→2022, но никогда не content authority для другого года. Каждый архивный год начинает собственный exact-year FIPI source prelock.

## PEIS boundary

Этот этап не создаёт Physics Identity Model, learner state, mastery/readiness/retention/NBA или новый evidence contract. Identity/evidence mapping начинается только после закрытия source/fidelity gate 2026 и последующего исторического source layer.
