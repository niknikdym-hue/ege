# Проверка алфавита и буквенных обозначений

Обязательное правило для всех интерактивных демоверсий ЕГЭ и ОГЭ.

## Требование

Буквенные обозначения в условии, таблице, элементах управления, автоматически собранном ответе и разборе должны совпадать с официальным источником по:

- алфавиту;
- регистру;
- порядку букв;
- знаку после буквы;
- количеству позиций.

Для русскоязычных заданий нельзя использовать CSS `upper-alpha` или `lower-alpha`: стандартные браузерные маркеры создают латинские `A, B, C...` и `a, b, c...`, даже когда данные задания используют кириллицу.

## Release gate

Перед выпуском пакет обязан:

1. Проверить все `prompt_html`, `criteria_html`, таблицы и подписи элементов управления на латинские маркеры, которых нет в официальном источнике.
2. Проверить вычисленный браузером `::marker` или `::before`, а не только исходный HTML/CSS.
3. Пройти проверку на всех поддерживаемых ширинах.
4. Блокировать релиз при любом расхождении между условием и интерактивными позициями.
5. Повторить эту проверку из чисто распакованного финального ZIP.

Правило применяется ко всем предметам независимо от типа задания.
