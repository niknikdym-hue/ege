# TILDA PUBLICATION GATE

Заполняется только после установки полного пакета и публикации страницы.

До прохождения этого gate статус остаётся `READY_FOR_TILDA_TEST`.

## 1. Адрес и метаданные

- [ ] Постоянный URL открывается с HTTP 200.
- [ ] Страница не возвращает Tilda 404.
- [ ] Canonical совпадает с постоянным URL.
- [ ] Title, Description, Keywords и slug не содержат год.
- [ ] Год актуального источника допустимо показан только в интерфейсе демоверсии.
- [ ] OG и JSON-LD не конфликтуют с canonical.
- [ ] На странице нет дублирующего canonical.

## 2. Установка T123

- [ ] Все T123 вставлены полностью.
- [ ] Порядок совпадает с INSTALLATION и EXAM MAP.
- [ ] Ни один блок не вставлен дважды.
- [ ] Нет пропущенного блока.
- [ ] Шапка и футер подключены отдельно и не дублируются внутри пакета.
- [ ] Визуальные стили соответствуют светлому стилю Эксамио.

## 3. Старт и состояние

- [ ] Начало новой попытки работает.
- [ ] Таймер показывает полное официальное время.
- [ ] Таймер продолжает идти после закрытия и возврата.
- [ ] После обновления доступно продолжение попытки.
- [ ] Текущий номер восстанавливается.
- [ ] Введённые ответы восстанавливаются.
- [ ] Отметки для возврата восстанавливаются.
- [ ] Варианты «ИЛИ» не меняются после перезагрузки.
- [ ] Сброс создаёт чистую попытку.

## 4. Навигация

- [ ] Белый — ответа нет.
- [ ] Зелёный — ответ сохранён.
- [ ] Оранжевый — отмечено для возврата.
- [ ] Синяя рамка — открытое задание.
- [ ] «Предыдущее» и «Следующее» работают на границах.
- [ ] «Отметить» и снятие отметки работают.
- [ ] «Завершить» требует подтверждения, если это предусмотрено пакетом.

## 5. Проверка ответов

- [ ] Пройден полный официальный набор правильных ответов.
- [ ] Проверены ключевые неправильные ответы из ACCEPTANCE CASES.
- [ ] Лишние символы не превращаются в правильный ответ.
- [ ] Альтернативные ответы принимаются только там, где подтверждены ФИПИ.
- [ ] Частичный балл работает на пограничных случаях.
- [ ] Зависимые критерии нельзя обойти через последовательность действий.

## 6. Развёрнутая часть

- [ ] Полное условие видно до ввода ответа.
- [ ] Все критерии раскрываются корректно.
- [ ] Все общие основания нуля видны.
- [ ] Неофициальная самооценка явно маркирована.
- [ ] Самооценка не выдаётся за официальный балл.
- [ ] Каскады и зависимости сохраняются после перезагрузки.

## 7. Ассеты

- [ ] Все официальные изображения отображаются.
- [ ] SVG не обрезаны.
- [ ] Подписи читаемы.
- [ ] Стрелки и геометрия совпадают с проверенным preview.
- [ ] Нет старых встроенных копий рисунков.
- [ ] Нет смешанного контента и ошибок загрузки.

## 8. Мобильные ширины

Проверить 320, 360 и 390 px на опубликованной странице:

- [ ] хлебные крошки не выходят за экран;
- [ ] навигация не создаёт горизонтальный скролл;
- [ ] таблицы и критерии помещаются;
- [ ] кнопки доступны;
- [ ] поля ответа не выходят за контейнер;
- [ ] SVG масштабируются;
- [ ] рекламные блоки не перекрывают интерфейс;
- [ ] sticky-панели не закрывают контент.

Дополнительно:

- [ ] 768 px;
- [ ] 1280 px.

## 9. Консоль и окружение

- [ ] Ошибок JavaScript нет.
- [ ] Ошибок JSON parse нет.
- [ ] Ошибок `localStorage` нет.
- [ ] Ошибок загрузки ассетов нет.
- [ ] Глобальные стили Tilda не ломают кнопки, select, textarea и SVG.
- [ ] Рекламные скрипты не ломают навигацию и сохранение.

## 10. Завершение и результат

- [ ] Завершение попытки работает.
- [ ] Краткая часть считает официальный максимум.
- [ ] Неправильные ответы дают ожидаемые баллы.
- [ ] Карточки разбора соответствуют выбранным вариантам «ИЛИ».
- [ ] Официальные ответы не показывались до завершения.
- [ ] Максимальная сумма совпадает с EXAM MAP.
- [ ] Неофициальные баллы не смешаны с официальными.
- [ ] Повторная попытка очищает состояние и выбирает новый набор вариантов по правилам.

## 11. Итог

- [ ] **PASS — PUBLISHED_SMOKE_PASS**
- [ ] **FAIL — вернуть статус READY_FOR_TILDA_TEST и исправить пакет/установку**
