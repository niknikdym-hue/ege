2. GRAPH CONSTRUCTION METHOD

The graph uses 12 stable top-level skills and 89 child subskills.

Rules applied:
- skill_id values describe durable subject concepts, not years or package versions;
- task number is evidence, not the definition of a skill;
- one task may link to several subskills;
- one trainer item may link to several subskills when its prompt contains
  several separately identifiable concepts;
- exact item links use the existing trainer_item_id without renaming it;
- all 174 trainer difficulty values are null because no validated difficulty
  measurements were found;
- all prerequisites arrays are empty because no prerequisite relation was
  sufficiently established as a fact by current materials;
- inference from prompt morphology is marked partial where the source lacks
  explicit machine metadata;
- contested relations use needs_review and are also present in review_queue.
