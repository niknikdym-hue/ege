EKSAMIO — ОБЯЗАТЕЛЬНЫЙ UX-СТАНДАРТ ДЛЯ РАЗВЁРНУТЫХ ОТВЕТОВ
Дата фиксации: 2026-08-13
Статус: ОБЯЗАТЕЛЬНО ДЛЯ НОВЫХ ГОДОВЫХ СБОРОК И ПРИ ДОРАБОТКЕ ПРИНЯТЫХ СБОРОК

1. ПРОФИЛЬНАЯ МАТЕМАТИКА — ОБЯЗАТЕЛЬНЫЙ ПАКЕТ РАБОТ

Для каждой годовой демоверсии ЕГЭ по профильной математике, где сохранена структура заданий с развёрнутым ответом, обязательны одновременно:

1.1. Удобный ввод математических символов в поле полного решения.
- Панель относится только к развёрнутым ответам; краткие ответы и их scorer не затрагиваются.
- Базовый набор: π, ∞, √(), ±, −, ≠, ≈, ≤, ≥, ·, ÷, ², ³, ⁴, ∥, ⊥, ∠, °, ∈, ∉, ∪, ∩, ∅, ℕ, ℤ, ℚ, ℝ, →, ⇒, ⇔.
- Нажатие вставляет символ в текущую позицию курсора.
- Для шаблонов типа √() курсор после вставки ставится внутрь скобок.
- Дополнительно поддерживаются быстрые преобразования: <= → ≤; >= → ≥; != → ≠; -> → →.
- Ученик не обязан знать LaTeX и не должен пользоваться внешним редактором формул.

1.2. Сопоставление собственного решения с официальным решением ФИПИ в результатах попытки.
- Для каждого задания с развёрнутым ответом после завершения попытки обязательно показывать сохранённый текст ученика с явным заголовком «Ваш ответ».
- Рядом/следом показывать официальный ответ, решение и критерии ФИПИ для фактически назначенного официального примера.
- Самооценка выполняется только после такого сопоставления.
- Ответ ученика не заменяется, не очищается и не скрывается после завершения попытки.
- Автоматический балл краткой части и самостоятельная оценка развёрнутой части остаются раздельными.

1.3. Ограничение изменений.
При добавлении этого UX в уже принятую годовую сборку запрещено одновременно менять содержание заданий, официальные ответы, варианты, scorer, input contracts краткой части, таймер, навигацию, state model или другую принятую экзаменационную логику без отдельного задания пользователя.

2. ФИЗИКА

Принцип обязателен для будущей работы с развёрнутыми ответами по физике:
- сохранять и показывать в результатах собственный развёрнутый ответ ученика рядом с официальным решением/критериями;
- давать предметно уместную панель символов и формул там, где обычной клавиатуры недостаточно;
- конкретный набор панели определяется официальными заданиями и реальными потребностями ввода, а не копируется механически из математики;
- автоматическую и самостоятельную части оценивания не смешивать.

3. ХИМИЯ

Для химии обязателен тот же принцип удобного предметного ввода и последующего сравнения своего ответа с официальным материалом, но реализация проектируется отдельно по структуре конкретного экзамена и года.
Ожидаемые предметные потребности могут включать нижние/верхние индексы, заряды ионов, стрелки реакций, степени окисления и другие химические обозначения. Математическую панель нельзя переносить в химию механически без предметного аудита.

4. ОБЯЗАТЕЛЬНЫЕ GATES ПЕРЕД ГОТОВНОСТЬЮ

Для предмета/года, где применяется этот стандарт, до статуса готовности проверить:
- панель появляется только там, где нужна;
- вставка идёт в позицию курсора;
- шаблоны ставят курсор в ожидаемое место;
- быстрые преобразования работают;
- введённый развёрнутый ответ сохраняется и восстанавливается после reload;
- до завершения попытки официальное решение не раскрывается;
- после завершения видны и «Ваш ответ», и официальный материал;
- собственный ответ выводится безопасно как текст, без интерпретации пользовательского HTML;
- самооценка остаётся отдельной от автоматического scorer;
- краткая часть и её scorer не изменены;
- мобильные ширины не получают горизонтального переполнения;
- T123 остаются в допустимом размере;
- после публикации выполнен production smoke-test.

5. ПРАВИЛО ДЛЯ БУДУЩИХ СБОРОК

Этот стандарт входит в ОБЯЗАТЕЛЬНЫЙ ПАКЕТ РАБОТ, а не является факультативным улучшением.
При создании профильной математики следующего года его нужно закладывать на этапе сборки движка и проверять отдельным acceptance gate.
Для физики и химии применять тот же UX-принцип с предметно адаптированным набором средств ввода.
