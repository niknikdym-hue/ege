ЦЕЛЕВАЯ МОДЕЛЬ ПЕРСОНАЛЬНОЙ ПОДГОТОВКИ К ЕГЭ

1. ГЛАВНЫЙ ПРИНЦИП

Базовая подготовка на Эксамио остаётся бесплатной.

Бесплатны:
- демоверсия ЕГЭ;
- тренажёр;
- банк тренировочных заданий;
- обычная проверка;
- работа над ошибками;
- базовая статистика;
- переход из демоверсии в тренировку слабых мест;
- накопление прогресса;
- повторение ошибок;
- базовый персональный маршрут;
- next-item correctness;
- spaced repetition;
- базовая карта слабых мест.

Платным становится не доступ к знаниям, а индивидуальная интеллектуальная работа системы с конкретным учеником: глубокая диагностика, AI-разбор, прогноз результата, долгосрочный адаптивный маршрут, проверка сочинений и другие вычислительно дорогие персональные функции.

2. ИЗ ДВУХ ПРОДУКТОВ ДЕЛАЕМ ОДНУ СИСТЕМУ

Сейчас:
Демоверсия -> человек проверил себя.
Тренажёр -> человек отдельно решил потренироваться.

Целевая логика:
Демоверсия -> диагноз -> тренировка -> проверка усвоения -> повторение -> новая контрольная -> обновлённый прогноз.

Пользователь не должен сам разбираться, что открыть после ошибки, сколько примеров решить и закрепил ли он тему. Это определяет Эксамио.

3. ЕДИНЫЙ ПРОФИЛЬ УЧЕНИКА

Не два независимых localStorage, а единый профиль:

  eksamio.student.russian

Он хранит:
- демоверсии;
- тренировки;
- задания;
- ответы;
- ошибки;
- время решения;
- изменения ответа;
- возвраты;
- закреплённые навыки;
- сомнительные навыки;
- повторные ошибки;
- рекомендации;
- результаты рекомендаций;
- давность последней практики.

MVP может жить без регистрации на устройстве. Позже профиль синхронизируется с сервером после входа в аккаунт.

4. SKILL GRAPH РУССКОГО ЯЗЫКА

Нельзя хранить только связь вида:
  задание 4 = орфоэпия.

Нужна иерархия:

ЕГЭ
└── Русский язык
    └── Задание 4
        └── Орфоэпические нормы
            ├── глаголы
            ├── причастия
            ├── деепричастия
            ├── прилагательные
            ├── существительные
            └── формы слов

Другие задания раскладываются по своим навыкам и поднавыкам.

Каждый тренировочный item получает:
- item_id;
- exam_task;
- skill;
- subskill;
- prerequisites;
- content_type;
- source_type;
- difficulty.

Если реальной статистики сложности пока нет:
  difficulty: null

Сложность позднее рассчитывается по фактическим данным, а не придумывается вручную.

5. ДЕМОВЕРСИЯ КАК ДИАГНОСТИЧЕСКИЙ ПРИБОР

Экзамен не адаптируем. Официальный порядок и формат не меняются.

Но невидимо собираем по каждому заданию:
- task_id;
- started_at;
- answered_at;
- response_time;
- answer;
- correct;
- score;
- answer_changes;
- marked_for_review;
- revisited.

Опционально позже:
- confidence: уверен / сомневаюсь / почти угадал.

Правильно + уверен и правильно + угадал — разные состояния знания.

6. КАРТА ПОТЕРЬ ПОСЛЕ ДЕМОВЕРСИИ

Показываем не только итоговый балл, а:

Сильные навыки
Требуют внимания
Где можно быстрее всего вернуть баллы

Основная бесплатная кнопка:
  Потренировать слабые места

Это нормальное продолжение обучения, а не реклама Premium.

7. DEMO -> TRAINER HANDOFF

После завершения демоверсии профиль ошибок передаётся в тренажёр.

Пример:
  demo failures: 4, 15, 21

Skill Graph уточняет:
  4 -> конкретный поднавык орфоэпии
  15 -> конкретный орфографический поднавык
  21 -> конкретная пунктуационная модель

Тренажёр автоматически собирает работу над ошибками. Пользователь не обязан вручную перенастраивать фильтры.

8. NEXT-ITEM CORRECTNESS

После ошибки в демоверсии ученик получает новый пример того же навыка.

DEMO:
  task 4 -> wrong

TRAINER:
  new item for same skill

Результат:
  next_item_correct = true / false

Это первый объективный сигнал: смог ли ученик после диагностики самостоятельно решить следующий релевантный пример.

9. НЕ ОГРАНИЧИВАЕМСЯ ОДНИМ NIC

Вводим несколько уровней:

NIC-1
- первое следующее задание.

NIC-3
- серия из нескольких новых заданий по навыку.

TRANSFER
- применение того же принципа в изменённой ситуации.

RETENTION
- выполнение через несколько дней.

Главная цель — не зелёная галочка сегодня, а отсутствие ошибки на реальном экзамене позже.

10. MASTERY SCORE

Каждый навык получает состояние знания, например:

0.00-0.29  не освоено
0.30-0.59  нестабильно
0.60-0.79  закрепляется
0.80-1.00  освоено

Mastery не равен простому проценту ответов.

На него влияют:
- правильность;
- сложность;
- несколько успехов подряд;
- повторные ошибки;
- давность практики;
- retention;
- transfer;
- количество попыток.

Первая версия должна быть прозрачной и детерминированной. AI здесь не нужен.

11. ОТЛИЧАЕМ НЕЗНАНИЕ ОТ СЛУЧАЙНОЙ ОШИБКИ

Система постепенно различает:
- knowledge_gap;
- невнимательность;
- непонимание формулировки;
- путаницу похожих правил;
- prerequisite gap;
- ошибку применения;
- ошибку после долгого раздумья;
- случайную ошибку.

Одиночная ошибка после серии успешных попыток не должна автоматически запускать двадцать повторений.

12. ERROR FINGERPRINT

У каждого ученика появляется индивидуальный отпечаток ошибок.

Не просто:
  Русский язык — 74%

А:
  Орфография
    Безударные гласные — уверенно
    Н/НН — нестабильно
    НЕ/НИ — уверенно
    Слитно/раздельно — слабое место

И глубже по поднавыкам.

Это долгосрочная память Эксамио.

13. ПЕРСОНАЛЬНЫЙ ТРЕНАЖЁР

Алгоритм выбора заданий по приоритету:
1. слабые навыки;
2. навыки с близкой потерей экзаменационного балла;
3. незакреплённые ошибки;
4. retention due;
5. давно не проверявшиеся навыки;
6. новые навыки;
7. освоенные — редко, для контроля.

Преимущество Эксамио: персонализация привязана к конкретной структуре ЕГЭ, а не к абстрактному обучению.

14. SPACED REPETITION

После успешной работы тема не исчезает.

Примерная последовательность:
  сегодня -> через 2 дня -> через 7 дней -> через 21 день

Интервалы корректируются результатами.

Пользователь видит не таблицу алгоритма, а:
  Сегодня стоит повторить 3 навыка · 8 минут.

15. ТРЕНИРОВКА НА СЕГОДНЯ

Это становится главным ежедневным UX.

Пример:
  Сегодня · 12 минут
  - 3 задания для закрепления
  - 2 ошибки из прошлой тренировки
  - 1 навык пора проверить повторно

Кнопка:
  Начать

Ручная настройка остаётся дополнительной возможностью.

16. ЦЕЛЬ В БАЛЛАХ

Ученик задаёт цель, например:
  80+
  минимум 70

Система учитывает не только mastery, но и экзаменационную ценность навыков.

17. САМЫЕ ДЕШЁВЫЕ БАЛЛЫ

Фирменная функция Эксамио.

Система анализирует:
- вероятность освоения;
- текущий mastery;
- ценность задания;
- время до экзамена;
- историю ошибок.

И показывает, где быстрее всего получить прирост результата.

18. ДИНАМИЧЕСКИЙ ПЛАН ДО ЭКЗАМЕНА

Входные параметры:
- дата экзамена;
- целевой балл;
- доступное время;
- дни занятий.

План автоматически перестраивается при пропусках и новых результатах.

19. КОНТРОЛЬНЫЕ ТОЧКИ

Нельзя бесконечно учиться только внутри тренажёра.

После определённого объёма работы система предлагает:
  Контроль

Без подсказок и мгновенных разборов.

Дальше:
  новая полная демоверсия.

Цикл:
  DEMO -> TRAINER -> RETENTION -> CONTROL -> DEMO

20. SCORE FORECAST

Продвинутая функция должна давать не ложную точность, а диапазон и неопределённость.

Пример:
  Прогнозный диапазон: 78-84
  Уверенность прогноза: средняя

Причины неопределённости тоже показываются.

21. CONFIDENCE CALIBRATION

Периодически ученик отмечает уверенность.

Позже Эксамио может выявить опасную зону:
  ученик уверен, но систематически ошибается.

Это важнее обычной ошибки, потому что такая проблема обычно не воспринимается самим учеником как проблема.

22. AI ПОДКЛЮЧАЕТСЯ ТОЛЬКО ПОВЕРХ СТРУКТУРИРОВАННЫХ ДАННЫХ

AI не должен получать огромную неструктурированную историю.

Он получает состояние вида:

skill: punctuation-X
mastery: 0.41
demo: failed
trainer: wrong, correct, correct
retention: failed
common_error: boundary identification
prerequisite: mastered

Только после этого начинается персональный AI-диалог.

23. AI-РЕПЕТИТОР НЕ ВЫДАЁТ ОТВЕТ СРАЗУ

Кнопка:
  Помоги разобраться

Лестница помощи:
1. микроподсказка;
2. наводящий вопрос;
3. указание места ошибки;
4. объяснение правила;
5. полный разбор.

После помощи обязательно даётся новый пример без помощи.

24. ОБЪЯСНИ МОЮ ОШИБКУ

AI объясняет не абстрактное правило, а конкретно:
  почему мой ответ оказался неверным.

Для этого он получает:
- условие;
- ответ ученика;
- правильный ответ;
- skill;
- relevant history.

25. AI НЕ ГЕНЕРИРУЕТ ОФИЦИАЛЬНЫЕ ФАКТЫ

Проверенные данные приходят из базы:
- формат;
- ответ;
- критерии;
- максимальный балл;
- структура задания;
- правила проверки.

AI может объяснять, задавать вопросы и строить персональный разбор, но не выдумывает нормы экзамена.

26. AI-ПРОВЕРКА СОЧИНЕНИЯ

Отдельная платная функция.

Система анализирует критерии по отдельности и показывает:
- что найдено;
- где найдено;
- что вызывает сомнение;
- какой критерий затронут;
- как исправить.

Формулировка:
  Предварительная учебная оценка AI.

Нельзя выдавать её за решение официального эксперта.

27. ПРОВЕРКА ФОТОГРАФИИ СОЧИНЕНИЯ

Пользователь фотографирует рукописную работу.

Пайплайн:
  распознавание -> подтверждение распознанного текста -> анализ -> замечания по конкретным фрагментам.

28. ПРОВЕРЬ ПОСЛЕ ИСПРАВЛЕНИЯ

AI-проверка не должна быть одноразовой.

После исправлений Эксамио сравнивает:
  было -> стало

И показывает, что исправлено, а что осталось.

29. ЛИЧНАЯ КНИГА ОШИБОК

Не список сотен попыток, а сгруппированная карта:
- активные слабые навыки;
- пора проверить;
- закреплено;
- вернулось после прошлой ошибки.

Для каждого навыка:
- почему ошибаюсь;
- последняя ошибка;
- потренировать;
- история.

30. ПАМЯТЬ НА МЕСЯЦЫ И ГОДЫ

Эксамио постепенно знает:
- какие правила ученик забывает;
- что путает;
- где слишком уверен;
- где решает медленно;
- какие подсказки помогают;
- сколько новых примеров обычно требуется для закрепления.

Это долгосрочное конкурентное преимущество продукта.

31. МЕТРИКИ ОБУЧЕНИЯ, А НЕ ENGAGEMENT

Главные метрики:
- next-item correctness;
- NIC-3;
- transfer success;
- retention;
- mastery gain;
- ошибки после повторения;
- прирост между контрольными попытками;
- время до закрепления навыка;
- AI help -> самостоятельное решение.

Время на сайте само по себе не является доказательством обучения.

32. ЭКСПЕРИМЕНТЫ

Каждое изменение алгоритма проверяется экспериментом.

Пример:
Алгоритм A: после ошибки сразу новый пример.
Алгоритм B: сначала prerequisite check.

Сравниваем NIC-1, NIC-3 и retention.

Победителя выбирают данные, а не ощущение команды.

33. RECOMMENDATION LOG

Каждая рекомендация сохраняется:
- student_state_before;
- recommendation;
- reason;
- item;
- result;
- student_state_after.

Позже это станет основой собственной модели выбора следующего действия.

34. КОНТРОЛЬНЫЕ ГРУППЫ

Сравниваем:
- обычный тренажёр vs адаптивный маршрут;
- разные типы объяснений;
- разные стратегии повторения.

Критерий успеха:
не лайк и не длина чата, а самостоятельное решение и retention.

Бесплатно:

Бесплатная версия должна быть настолько хороша, чтобы её хотелось рекомендовать.

36. ЗА ЧТО ПЛАТИТ ПОЛЬЗОВАТЕЛЬ

Платит за персональную вычислительную работу:
- глубокий AI-разбор ошибки;
- диалог с AI-репетитором;
- анализ причины системной ошибки;
- AI-проверка сочинения;
- повторная AI-проверка исправленного сочинения;
- анализ рукописной работы;
- расширенный прогноз результата;
- персональный план до конкретной даты;
- прогноз, где быстрее добрать баллы;
- продвинутая аналитика динамики.

37. ЧТО НЕ ДЕЛАЕМ

Не создаём модель:
  Premium — 5000 заданий, Free — 50.

Не скрываем ответы за paywall.
Не блокируем работу над ошибками.
Не делаем аккаунт обязательным для старта.
Не заставляем пользоваться AI ради AI.
Не генерируем бесконечные задания сомнительного качества только потому, что это технически возможно.

Наше преимущество:
  не «мы можем сгенерировать ещё вопрос»,
  а «мы знаем, какой проверенный вопрос нужен тебе следующим и почему».

38. ГЛАВНАЯ ПРОДУКТОВАЯ ЕДИНИЦА

Не страница, не задание и не сессия.

Главная единица — Learning Loop:

DIAGNOSE
-> SELECT
-> PRACTICE
-> HELP
-> VERIFY
-> RETAIN
-> REASSESS

Каждый круг должен повышать вероятность самостоятельного правильного выполнения.

39. КАК СТАТЬ ЛУЧШЕ МИРОВЫХ ПРОДУКТОВ

Универсальные мировые платформы решают тысячи учебных сценариев. Эксамио может быть глубже именно в ЕГЭ и ОГЭ.

45. КОНЕЧНЫЙ ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ

День 1:
ученик проходит демоверсию.

Эксамио показывает не только результат, но и слабые навыки и предлагает короткую бесплатную тренировку.

После тренировки:
часть навыков закрепляется, часть остаётся нестабильной.

Через несколько дней:
retention-проверка.

Через две недели:
контрольная или новая демоверсия.

Эксамио показывает динамику и следующий реалистичный резерв роста.

Только после того как бесплатная часть уже доказала пользу, платная часть предлагает глубокий AI-анализ, персональный долгосрочный план и расширенный прогноз.

ИТОГОВАЯ ФОРМУЛА ЭКСАМИО

БЕСПЛАТНО:
Проверить -> найти проблему -> потренироваться -> проверить, что проблема исправлена.

ПЛАТНО:
Понять причину -> получить глубокую персональную помощь -> оптимизировать маршрут -> прогнозировать результат.

ГЛАВНЫЙ ПРИНЦИП РАЗРАБОТКИ:
Эксамио не должно измерять только количество выполненных заданий. Эксамио должно измерять, чему ученик научился и сохранилось ли это знание.

Русский язык используется как эталонный пилот. После успешной реализации ядро переносится на математику, физику, обществознание и другие предметы как единый Eksamio Learning Engine.
