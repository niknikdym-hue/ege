AUDIT PRINCIPLE

Do not write learner-facing rule text before locating a reliable rule source.
Existing trainer steps/traps are a baseline UX artifact, not sufficient source evidence by themselves.
If sources differ in formulation, preserve the stable linguistic rule and document the difference internally.
If an exception/edge case cannot be confirmed, mark NEEDS_REVIEW instead of simplifying it into a false rule.
