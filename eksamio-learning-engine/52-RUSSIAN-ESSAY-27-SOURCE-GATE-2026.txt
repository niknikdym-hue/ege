OFFICIAL TASK 27 MODEL CONFIRMED

Задание 27 — сочинение-рассуждение на основе прочитанного исходного текста.
Проверяется экспертами предметных комиссий.
Максимум: 22 первичных балла.
Критерии: К1–К10.

К1 — позиция автора (рассказчика) по указанной проблеме.
К2 — комментарий к позиции автора.
К3 — собственное отношение экзаменуемого к позиции автора и его обоснование.
К4 — фактическая точность речи.
К5 — логичность речи.
К6 — соблюдение этических норм.
К7 — орфографические нормы.
К8 — пунктуационные нормы.
К9 — грамматические нормы.
К10 — речевые нормы.

CRITICAL GATES

GATE 1 — К1
Если позиция автора (рассказчика) по указанной проблеме не сформулирована или сформулирована неверно:
- К1 = 0;
- К2 = 0;
- К3 = 0.

Следствие для Learning Engine:
нельзя вести ученика к комментарию или собственному отношению как к независимым от К1 блокам. Сначала должна быть проверена смысловая опора: понял ли ученик позицию автора по именно указанной проблеме.

GATE 2 — ОБЪЁМ
Нормы К7–К10 рассчитаны на работу объёмом 150 слов и более.
Если в сочинении 149 слов или меньше:
- работа не засчитывается;
- К1–К10 = 0;
- задание считается невыполненным.

При подсчёте слов действуют правила ФИПИ, включая учёт самостоятельных и служебных частей речи; отдельные технические элементы и переписанная информация из формулировки задания могут не входить в учитываемый авторский объём по правилам ФИПИ.

Следствие для Learning Engine:
счётчик слов может быть только технической подсказкой. Нельзя выдавать браузерный автоматический подсчёт за окончательное экспертное решение без соответствия официальным правилам подсчёта.

GATE 3 — ОПОРА НА ИСХОДНЫЙ ТЕКСТ
Работа без опоры на прочитанный текст не оценивается.
Полностью переписанный или пересказанный исходный текст без собственного комментария оценивается 0 по К1–К10.
При частичном переписывании/пересказе для объёма учитывается авторская часть работы по правилам ФИПИ.

Следствие для Learning Engine:
нельзя считать наличие 150+ технически подсчитанных слов достаточным условием выполнения задания.

K2 STRUCTURE CONFIRMED

Для максимума по К2 необходимы одновременно:
- опора на исходный текст;
- 2 примера-иллюстрации, важные для понимания позиции автора по указанной проблеме;
- пояснение к каждому примеру;
- смысловая связь между примерами;
- пояснение этой смысловой связи.

Если пример приведён, но не пояснён, этот пример не засчитывается как полноценный пример-иллюстрация по К2.
Фактическая ошибка в комментарии учитывается по К4.

K3 STRUCTURE CONFIRMED

Для максимума по К3 необходимы:
- сформулированное собственное отношение к позиции автора по указанной проблеме;
- обоснование этого отношения;
- пример-аргумент.

Допустимый источник примера-аргумента:
- читательский опыт;
- историко-культурный опыт;
- жизненный опыт.

Пример-аргумент не должен повторять авторские суждения.
ФИПИ отдельно перечисляет виды медиаконтента, которые не засчитываются как источник примера-аргумента; learner-facing интерфейс должен передавать это ограничение кратко и без расширительного толкования.

K4–K6 CONFIRMED

К4 — фактическая точность:
- без фактических ошибок: 1;
- одна или более фактических ошибок: 0.

К5 — логичность:
- 0 логических ошибок: 2;
- 1–2 ошибки: 1;
- 3 и более: 0.

К6 — этические нормы:
- без этических ошибок: 1;
- при наличии нарушений, подпадающих под официальный критерий: 0.

K7–K10 COMMON ERROR SCALE CONFIRMED

Для каждого из критериев К7, К8, К9, К10 применяется одинаковая числовая шкала:
- 0 ошибок: 3;
- 1–2 ошибки: 2;
- 3–4 ошибки: 1;
- 5 и более ошибок: 0.

Но тип ошибки различается:
- К7 — орфографические;
- К8 — пунктуационные;
- К9 — грамматические;
- К10 — речевые.

7. Текущий production trainer остаётся неизменным до отдельного integration gate.
