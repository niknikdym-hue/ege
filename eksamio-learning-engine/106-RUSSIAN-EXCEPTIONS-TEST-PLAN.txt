- correct option accepted;

- missing one option rejected/partial only if contract explicitly allows partial;
- extra option rejected.

short_text / normalize_form
Test:
- surrounding whitespace;
- case handling if case-insensitive by contract;
- Ё/Е handling only if that exact item declares equivalence;
- hyphen vs dash normalization only where typographic normalization is allowed;
- internal spaces meaningful for `на встречу`, `в течение`, etc.;
- do not normalize away orthographic distinctions being tested.

- expected class only;
- display wording does not alter internal answer code.

- set comparison;
- duplicate entered positions normalized/rejected predictably;
- no accidental partial acceptance from substring matching.
