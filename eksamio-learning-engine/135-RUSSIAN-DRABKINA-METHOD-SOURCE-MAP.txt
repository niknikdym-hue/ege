PARONYMS / LEXICAL NORMS

Drabkina / Subbotin EGE materials use the useful teaching model:
- formulate the meaning of each paronym;
- identify typical collocations;
- compare the pair in context;
- choose by meaning and compatibility, not by common root.

For the current repository split, an exact page/section locator for every paronym pair has not yet been assigned to a specific local PDF. Therefore:
- DO use this method for learner design;
- DO NOT fabricate a precise Drabkina PDF/page locator;
- normative meanings/collocations must be confirmed by a current explanatory/paronym dictionary or Gramota.ru;
- internal provenance may reference this method map until a local exact locator is recorded.

MORPHOLOGICAL NORMS / DIFFICULT FORMS

Use Drabkina tables/grouping as a teaching method when the local section is confirmed.
Normative forms such as ДОКТОРА, КУПОЛА, ПОЛОТЕНЕЦ, ПОМИДОРОВ, ВОРОТ must additionally be checked against a current normative dictionary/reference.
Do not attribute these forms to project `rozental.doc` unless the exact project text really contains the relevant norm.

SYNTAX / GOVERNMENT

Use Drabkina task-8 style algorithms for learner diagnostics:
- identify construction type;
- ask the governing question;
- compare requirements of each governing word;
- rebuild the phrase/sentence;
- verify the boundary case.

Normative government and syntax boundaries must be supported by an appropriate current grammar/reference source. Do not label them generically as `Rosenthal: syntax` when the project Rosenthal file is an orthography/punctuation reference.

CURRENT-NORM OVERRIDES ALREADY FOUND

1. `заревать` — current learner form; historical `зоревать` must not be taught as a current exception.
2. `в конце концов` — context-sensitive function; do not teach as universally non-introductory.
3. `СКАК-/СКОК-/СКАЧ-/СКОЧ-` — use the fuller current model; do not reduce to the old school mnemonic with `скачок/скачу` as unexplained exceptions.
4. When an older table conflicts with current academic/dictionary norm, preserve the table's pedagogical logic only after updating the linguistic content.
