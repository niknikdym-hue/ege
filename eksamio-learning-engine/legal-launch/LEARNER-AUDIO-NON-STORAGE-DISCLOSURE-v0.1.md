# Голосовой Tutor — раскрытие о не-хранении аудио v0.1

**СТАТУС: PRODUCT RULE READY / BLOCKED_EXTERNAL FOR PUBLICATION**

Канонический продуктовый инвариант Eksamio: **аудио ученика не сохраняется Eksamio**.

## Что допускается

Голосовая реплика может быть временно обработана только для распознавания текущего взаимодействия с Tutor и передачи результата в допущенный учебный контур.

## Что запрещено сохранять

- исходную аудиозапись ученика;
- фрагменты записи и резервные копии аудио;
- voiceprint / speaker profile;
- постоянные speaker/voice embeddings;
- иные акустические представления для последующей идентификации или повторного использования голоса.

`learner_audio_persisted = 0` является launch-critical acceptance invariant.

## Что требуется до публикации

1. Проверить production implementation и логи: Eksamio persistence count для learner audio = 0.
2. Проверить фактические настройки и договорные условия SpeechKit/другого допущенного провайдера на предмет непредусмотренного retention.
3. Убедиться, что публичная политика персональных данных описывает реальный transient flow без обещаний, которые код/провайдер не выполняют.
4. Принять точную версию этого disclosure вместе с остальным legal artifact set.

До выполнения этих пунктов документ остаётся `BLOCKED_EXTERNAL` и не является юридическим acceptance.
