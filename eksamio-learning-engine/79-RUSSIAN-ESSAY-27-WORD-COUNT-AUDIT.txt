FUTURE WORD COUNTER REQUIREMENTS

A future learner-facing counter may be useful, but it must have two explicitly separate concepts:

A. TECHNICAL LIVE COUNT
Purpose:
- help the learner monitor approximate volume while writing.

UI wording must clearly identify it as a technical/working count unless full FIPI equivalence has been validated.

B. FIPI-COMPATIBLE FINAL COUNT
Purpose:
- evaluate the official 150-word gate for a completed essay.

This mode must not be implemented until:
1. the exact current FIPI 2026 word-count rules are transcribed into a machine-testable specification;
2. edge cases are enumerated;
3. test fixtures cover each edge case;
4. the implementation matches the fixtures;
5. an independent audit confirms equivalence.

REQUIRED FUTURE TEST CLASSES

At minimum audit the official handling of:
- ordinary whitespace-separated words;
- initials and surname constructions;
- numerals written with digits;
- hyphenated compounds;
- separate particles/prepositions/conjunctions;
- abbreviations;
- quoted material;
- copied source-text fragments where official evaluation rules distinguish them;
- punctuation-attached tokens;
- em dash / hyphen boundaries;
- line breaks and repeated spaces.

IMPORTANT

The list above is a TEST-PLANNING LIST, not a statement of what FIPI counts as one or multiple words in each case.
Do not implement behavior from this list without the verified official counting rule.
