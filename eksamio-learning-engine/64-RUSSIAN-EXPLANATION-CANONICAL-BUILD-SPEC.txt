3. MERGE ORDER

A. Parse every base source JSON independently.
Failure to parse ANY required source = BUILD FAIL.

B. Collect all base `units` by `explanation_id`.
Duplicate explanation IDs are forbidden.
No silent last-write-wins behavior.

C. Apply file 63 overlay by `explanation_id`:
- target must exist exactly once in the base source set;
- replace/add only `examples`;
- preserve rule, algorithm, Skill Graph links and source refs;
- missing target = BUILD FAIL;
- duplicate overlay target = BUILD FAIL.

D. Append internal split units from files 61, 62, 67, 72 and 80:
- every split `explanation_id` must be unique;
- split explanation IDs are presentation/routing units, NOT new Skill Graph nodes;
- their `subskill_ids` point to accepted Skill Graph nodes;
- parent broad explanation remains as safe fallback.

E. Essay units from file 55 are part of the base source set.
`essay_ethics_review` may have an empty `subskill_ids` array because the accepted Skill Graph intentionally has no dedicated ethics subskill.
