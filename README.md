# Eksamio

Репозиторий учебной платформы Эксамио: интерактивные демоверсии ЕГЭ, тренажёры, предметные source-корпуса и новая система персонального обучения.

## Архитектурная граница

`eksamio-learning-engine/` — корень новой системы Эксамио внутри общего репозитория `ege`.

Перед любой новой продуктовой или архитектурной работой по этой системе прочитать:

1. `eksamio-learning-engine/00-PRODUCT-MASTERPLAN.md` — целевой продукт, архитектура и приоритеты.
2. `eksamio-learning-engine/AGENTS.md` — обязательный порядок работы и safety rules.
3. Указанную в них current subject/source authority chain.

Для работы с самими демоверсиями дополнительно обязателен `00-READ-FIRST-EGE-DEMOVERSII-MASTER.md` и предметные регламенты/source gates.

## Главный принцип

Демоверсии, тренажёры и полная предметная программа не должны превращаться в независимые острова. Новая система постепенно связывает их одним learning loop и одним Student Model:

`diagnose -> model -> prioritize -> practice/help -> verify -> retain -> reassess -> replan`

Официальное экзаменационное содержание и scoring остаются deterministic/source-controlled. AI подключается поверх проверенной структуры и не является источником истины.
