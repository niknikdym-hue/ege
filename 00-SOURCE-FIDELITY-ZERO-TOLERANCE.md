# 00 — SOURCE FIDELITY ZERO-TOLERANCE STANDARD

**СТАТУС: ОБЯЗАТЕЛЬНО ДЛЯ ВСЕХ ИНТЕРАКТИВНЫХ ДЕМОВЕРСИЙ ЕГЭ/ОГЭ.**
Дата фиксации: 2026-08-14.

Этот документ регулирует работу с первоисточником и допуск готовой демоверсии к выдаче. Он имеет приоритет над любыми более старыми формулировками, разрешавшими реконструкцию официальных визуалов.

## 1. Точность
Демоверсия должна соответствовать официальному первоисточнику конкретного года на 100%. Любое расхождение, сомнение, неполная сверка или невозможность доказать совпадение означает `NO GO`.

Не являются доказательством точности: «по смыслу совпадает», «математически эквивалентно», «визуально похоже», «ответ получается тот же», «реконструировано по исходнику», «восстановлено по официальному ответу».

## 2. Источник истины
Только официальный комплект нужного года: демоверсия, спецификация, кодификатор, официальные ответы, критерии, справочные материалы и иные официальные файлы ФИПИ/федерального источника.

Нельзя подменять первоисточник старым ZIP, соседним годом, сторонним сайтом, предыдущим чатом, JavaScript-данными, памятью исполнителя или логическим восстановлением.

## 3. Визуалы
Если официальный PDF содержит рисунок, график, схему, карту, чертёж, диаграмму, таблицу-изображение или иной визуальный фрагмент условия, в демоверсии используется только изображение, полученное непосредственно из официального первоисточника.

Разрешены только: render официальной PDF-страницы, crop нужного фрагмента, поворот, безопасный resize без потери читаемости, техническая конвертация PNG/WebP без изменения содержания.

Запрещены: SVG/Canvas/HTML-реконструкции вместо исходника, ручная перерисовка линий/осей/точек/подписей/фигур/часов/карт/графиков, реконструкция по смыслу или по ответу, «улучшение» геометрии/масштаба/подписей/композиции, вторичный сайт как visual source.

Если exact source crop/asset получить нельзя, `VISUAL_GATE = FAIL` и пакет не выдаётся.

## 4. Строка ФИПИ «Ответ: ______»
Печатную строку `Ответ: ______` вместе с линией ответа в интерактивную демоверсию НЕ переносить.

При source crop разрешено исключить только эту строку и линию. Нельзя затрагивать условие, рисунок, подписи, оси, числовые отметки, единицы или геометрию. Системное поле ответа Эксамио остаётся отдельным интерактивным контролом.

## 5. Текст и формулы
Официальный текст сверяется фактически, а не пересказом. Нельзя сокращать, дописывать или литературно редактировать условие.

Формулы сохраняют все символы, индексы, степени, корни, дроби, интервалы, знаки и структуру источника. Математическая эквивалентность не разрешает менять официальное представление.

## 6. Source evidence
Для каждого source visual в `ASSET-MAP` / source evidence фиксируются: официальный filename, SHA/идентификатор, страница, crop/однозначная ссылка на фрагмент, итоговый asset filename, four-edge check и desktop/mobile readability. Без этого visual PASS запрещён.

## 7. Независимый финальный аудит
После рабочего аудита готового ZIP обязателен отдельный независимый финальный аудит с нуля по первоисточнику и чисто распакованному ZIP. Предыдущие PASS-флаги не принимаются как доказательство.

Любой найденный дефект снимает READY до исправления и повторной независимой проверки затронутой области.

## 8. READY_FOR_TILDA
`READY_FOR_TILDA` разрешён только после PASS всех обязательных gates: SOURCE, TEXT/TYPOGRAPHY, FORMULA, VISUAL_SOURCE с source-origin evidence, INTERACTION, SCORER, STATE, T123 SIZE, clean-ZIP browser regression и independent final audit. Наличие `ASSUMED` / `UNVERIFIED` / `TODO` / `PENDING` или reconstructed official visuals = `NO GO`.

## 9. Приоритет
С 2026-08-14 любые более старые разрешения на реконструкцию official visuals «при технической необходимости» считаются отменёнными.
